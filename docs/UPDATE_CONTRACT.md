# 条纹纺织调色外部更新契约

当前主程序不联网检查更新，也不自动替换自身。它为后续独立更新器提供稳定契约，更新器可以单独开发和分发。

## 稳定身份与数据

- 应用 ID 固定为 `com.kurokid.stripestudio`。
- 用户数据固定保存在 `%APPDATA%\StripeStudio`，不随 EXE 文件名、存放目录或版本变化。
- 更新器只能替换主程序 EXE，不能删除或覆盖该数据目录。
- 项目文件格式版本为 4，固定资产格式版本为 2，持久化仓库版本为 1。

## 运行信息

主程序启动后会写入：

`%APPDATA%\StripeStudio\desktop-runtime.json`

其中包含当前版本、便携 EXE 路径、实际进程路径、数据目录、运行状态和数据兼容版本。未来更新器应以 `launcherPath` 作为待替换的主程序路径，但仍须验证它确实指向本应用。

主程序还会在每次启动时登记当前用户注册表：

`HKCU\Software\Kurokid\StripeStudio`

其中 `LauncherPath` 是主便携 EXE 的当前位置，`RuntimeInfoPath` 指向上述运行信息文件。主程序移动到其他目录并再次运行后，这两处位置会自动刷新。未来更新器本身可以放在任何目录，优先读取注册表，再读取运行信息文件，不依赖与主程序同目录。

如果用户移动主程序后从未在新位置运行，Windows 不会自动知道新路径。更新器在登记路径失效时应扫描常用目录和已连接磁盘，仍找不到时才让用户手动选择一次。

## 安全退出

未来更新器在替换文件前运行：

`条纹纺织调色.exe --shutdown-for-update`

如果主程序正在运行，该参数会被已有实例接收，主程序将正常退出并刷新运行状态；如果没有实例运行，命令会直接正常结束，不打开界面。

## 建议更新流程

1. 下载新版到临时目录。
2. 校验发布清单、SHA-256 和数字签名。
3. 读取注册表和 `desktop-runtime.json`，交叉验证应用 ID、旧版本和主程序路径。
4. 请求旧版安全退出，并等待相关进程完全结束。
5. 将旧 EXE 改名为可回滚备份，再原位放入新版 EXE。
6. 启动新版并确认其写入新的运行信息。
7. 成功后删除备份；失败则恢复旧 EXE。

更新器不得把项目文件、固定资产或用户色库打包进版本更新，也不得清理 `%APPDATA%\StripeStudio`。
